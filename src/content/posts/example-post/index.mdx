This is an example post. Replace it or delete the `example-post` folder.

You can use **bold**, *italic* and [links](https://astro.build) as in Markdown.

## A list

- Each post lives in its own folder under `src/content/posts/`.
- The folder name becomes the URL.
- Set `draft: true` in the frontmatter to hide a post.

## Code

```ts
export function greet(name: string): string {
  return `Hello, ${name}`;
}
```

## Escaping

In MDX, a curly brace or an angle bracket outside a code block starts JSX. Write \{ and \< to show them as text.

Minimalistic module for quickshell used to show sync lyrics floating over the desktop. It was created with a minimalist philosophy, aiming to allow users to view lyrics while multitasking, all while consuming minimal resources.

Works with any MPRIS players and has extra controls to be used with [Spotify-player](https://github.com/aome510/spotify-player) module for which this module was originally intended
